# Kuldeep Prajapat — Academic Website

**Live website:** https://prajapat-kuldeep.github.io/kuldeep-prajapat/

This repository contains the source for the academic website of Kuldeep Prajapat, Ph.D. scholar in the School of Physical Sciences at the Indian Institute of Technology Mandi, India.

The site presents research interests and academic work in theoretical and computational atomic, molecular, and optical physics, including atomic clusters, fullerenes and endohedral systems, photoionization, electron correlation, interatomic Coulombic decay, photoelectron angular distributions, and attosecond time delays.
